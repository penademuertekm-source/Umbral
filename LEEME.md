# Kit de arranque · Umbral

Este kit se descomprime en la carpeta del proyecto **antes** de abrir Claude Code.

| Carpeta / archivo | Para qué sirve |
|---|---|
| `CLAUDE.md` | Memoria del proyecto: Claude Code la lee sola en cada sesión. |
| `docs/PROMPTS.md` | Los prompts por fases (0 a 11), para copiar y pegar. **Empieza aquí.** |
| `docs/especificacion-pantallas.md` | Las 23 pantallas con su nodo de Figma, sus reglas y la navegación. |
| `design/tokens.css` | Colores, espaciado, radios, elevación y tipografía exportados de Figma. |
| `design/iconos/` | Los 42 íconos en SVG (24 px, trazo 2). |
| `design/marca/` | Isotipo en positivo, negativo y una tinta. |
| `datos/` | Plantillas de datos provisionales y su explicación. |

Orden: lee `docs/PROMPTS.md` → Fase 0 → Fase 1…
